# Правила для кодинг-агента

Этот репозиторий — учебный Telegram AI Bot Starter для Hardcoding PRO. **Адаптируй копию ученика**, не меняй чужие проекты и фоновые процессы.

1. Прочитай README.md, LESSON_01.md, ARCHITECTURE.md, PROMPT_ADAPT.md и код; проверь ветку, Git status и тесты.
2. Не переписывай проект без необходимости. Сохраняй aiogram 3, SQLite, OpenAI-compatible API, `/start`, `/help`, `/reset`.
3. Секреты, `.env`, SQLite с перепиской — **никогда** не помещать в Git или чат.
4. При изменении функции дополни тесты. Запусти `pytest -q`, `ruff check .`, `python -m compileall -q bot`.
5. Реальную Telegram-проверку делай только с доступным токеном собственного тестового бота; при отсутствии ключей **не утверждай успех E2E**.
6. Для значимых изменений используй ветку и PR. Не делай автоматический merge без разрешения владельца.
7. Финальный отчёт: Сделано → Проверено → Не проверено → Как запустить → Следующий шаг.
